# الإشعارات

شاشة الإشعارات تعرض جميع إشعارات النظام في مكان واحد — الإعلانات، نتائج الاختبارات، تنبيهات الحضور، مهام سير العمل، رسائل الدردشة، نشاط القرص الذكي، الحوادث السلوكية، والمزيد. الإشعارات ثنائية اللغة (الإنجليزية والعربية) وتتضمن تفاصيل سياقية مثل اسم المرسل واسم الفصل وحالة الطالب.

تُولّد الإشعارات تلقائياً بواسطة النظام عند حدوث أحداث. تتلقى الإشعارات الموجهة إليك مباشرة، أو إلى دورك، أو إلى فصل أنت عضو فيه. شارة غير مقروءة في الوقت الفعلي في الشريط العلوي تبقيك على اطلاع بالنشاط الجديد.

## من يمكنه الوصول

| الدور | العمليات | ما يمكنهم فعله |
| --- | --- | --- |
| المشرف العام | عرض، تحديث | عرض وإدارة جميع الإشعارات |
| المشرف | عرض، تحديث | عرض وإدارة الإشعارات |
| الموارد البشرية | عرض، تحديث | عرض وإدارة الإشعارات |
| المدرب | عرض، تحديث | عرض وإدارة إشعاراتهم |
| الطالب | عرض، تحديث | عرض وإدارة إشعاراتهم |

> **معرف الشاشة:** `notifications` — يتطلب عملية `view`. `update` مطلوبة للتعليم كمقروء/غير مقروء.

## قنوات تسليم الإشعارات

تُسلّم الإشعارات عبر قنوات متعددة:

| القناة | الوصف |
| --- | --- |
| **درج الإشعارات داخل التطبيق** | درج منزلق قابل للوصول من أيقونة الجرس في الشريط العلوي. يعرض الإشعارات الأخيرة مع الأيقونات وألوان الفئات والروابط المباشرة. |
| **صفحة الإشعارات** | عرض صفحة كاملة على `/notifications` مع تصفية وإجراءات بالجملة وسجل كامل. |
| **شارة غير مقروء في الشريط العلوي** | عدد الإشعارات غير المقروءة في الوقت الفعلي يُعرض على أيقونة الجرس. يتحدث عبر WebSocket. |
| **البريد الإلكتروني** | تسليم بريد إلكتروني اختياري بناءً على تفضيلات الإشعارات المُكونة في [الملف الشخصي والإعدادات](/ar/profile). |
| **إشعارات الدفع في المتصفح** | إشعارات دفع اختيارية في المتصفح. تتطلب إذن المتصفح. |

## الإجراءات الرئيسية

- **قراءة الإشعارات** — انقر على إشعار لعرض تفاصيله الكاملة. بعض الإشعارات تتضمن روابط مباشرة للشاشة ذات الصلة.
- **التعليم كمقروء/غير مقروء** — تبديل حالة القراءة فردياً أو بالجملة.
- **تصفية** — تصفية حسب النوع أو نطاق التاريخ أو مستوى الأهمية.
- **ألوان الفئات** — كل فئة إشعارات لها لون مميز للتعرف البصري السريع:

  | الفئة | اللون |
  | --- | --- |
  | التقييم | أزرق |
  | التواصل | كهرماني |
  | الإعلانات | سماوي |
  | الحضور | برتقالي |
  | سير العمل | بنفسجي |
  | السلوك | وردي |
  | الملفات / القرص | نيلي |
  | QR | تركواز |
  | المشاركة | أخضر |
  | العقوبة | أحمر |
  | الموارد | نيلي |
  | الأكاديمي | أزرق |
  | النظام | رمادي |

- **الإعدادات** — تكوين أي الإشعارات تتلقاها عبر صفحة [الملف الشخصي والإعدادات](/ar/profile).

## تفاصيل حمولة الإشعار

جميع حمولات الإشعارات مُثراة بتفاصيل سياقية ثنائية اللغة (إنجليزي/عربي):

- **اسم المرسل** — اسم العرض المُترجم للمستخدم الذي أطلق الإشعار.
- **نوع المستلم** — `user` أو `users` أو `role` أو `class` — يحدد من يتلقى الإشعار.
- **تفاصيل المستلم** — `recipientUserId` أو `recipientRole` أو `recipientClassId` حسب نوع المستلم.
- **متغيرات سياقية** — اسم الفصل (ثنائي اللغة)، اسم الطالب (ثنائي اللغة)، الحالة، التاريخ، اسم الملف، اسم المجلد، إلخ.
- **رابط مباشر** — URL مباشر للشاشة أو السجل ذي الصلة.
- **الأولوية** — مستوى أولوية الإشعار (معلومات، تحذير، عاجل).
- **الفئة** — فئة بصرية لتلوين الكود في الدرج وصفحة الإشعارات.

## القواعد والتحقق

- **شارة غير مقروء** — يعرض الشريط العلوي عدداً للإشعارات غير المقروءة. يتحدث في الوقت الفعلي عبر WebSocket.
- **التعليم التلقائي كمقروء** — النقر على إشعار يعلمه تلقائياً كمقروء.
- **الاحتفاظ** — تُحتفظ الإشعارات لمدة 90 يوماً. الإشعارات الأقدم تُؤرشف ولم تعد مرئية.
- **نطاق لكل مستخدم** — يمكنك فقط رؤية الإشعارات الموجهة إليك أو إلى دورك أو إلى فصل أنت عضو فيه.
- **إجراءات بالجملة** — يمكنك تعليم حتى 50 إشعار كمقروء/غير مقروء في إجراء واحد.
- **دعم ثنائي اللغة** — جميع محتوى الإشعارات متاح بالإنجليزية والعربية، ويُعرض حسب تفضيل لغتك.
- **تسليم فوري** — تُدفع الإشعارات في الوقت الفعلي عبر WebSocket. لا حاجة لتحديث الصفحة.

## القيود

- لا يمكنك حذف الإشعارات — فقط تعليمها كمقروء أو غير مقروء.
- تسليم البريد الإلكتروني للإشعارات يعتمد على إعدادات ملفك الشخصي وتكوين قالب البريد.
- إشعارات الدفع (المتصفح) تتطلب منح الإذن في إعدادات المتصفح.
- سجل الإشعارات محدود بـ 90 يوماً. للمسارات التدقيقية الأطول، استخدم سجلات الإشعارات في [لوحة التحكم](/ar/dashboard).

## استكشاف الأخطاء وإصلاحها

| المشكلة | الحل |
| --- | --- |
| شارة غير مقروء تعرض عدداً خاطئاً | حدّث الصفحة. تُزامن الشارة عند تحميل الصفحة وعبر WebSocket. إذا استمرت، امسح ذاكرة التخزين المؤقت وأعد التحميل. |
| لا تتلقى إشعارات البريد الإلكتروني | تحقق من تفضيلات الإشعارات في [الملف الشخصي والإعدادات](/ar/profile). تحقق من صحة عنوان بريدك الإلكتروني. |
| إشعارات الدفع في المتصفح لا تعمل | تحقق من إعدادات المتصفح ← أذونات الموقع ← الإشعارات. تأكد من السماح بالإشعارات لهذا الموقع. |
| الإشعارات القديمة اختفت | تُحتفظ الإشعارات لمدة 90 يوماً. الأقدم تُؤرشف ولم تعد مرئية. |
| لا يمكن تعليم الإشعارات كمقروء | جرب تحديث الصفحة. إذا استمرت المشكلة، تحقق من اتصال الشبكة. |
| الإشعارات ليست بلغتي | تحقق من تفضيل اللغة في [الملف الشخصي والإعدادات](/ar/profile). جميع الإشعارات ثنائية اللغة وتُعرض بناءً على إعداد لغتك. |
| إشعارات مفقودة لفصل | تأكد من أنك مسجل في الفصل أو مُعين كمدربه. تُرسل الإشعارات فقط لأعضاء الفصل. |
