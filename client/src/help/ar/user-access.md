# صلاحيات وصول المستخدم

يستخدم النظام **خمس طبقات** للتحكم في الوصول. مدير النظام (Super Admin) يحدد ما يمكن لـ HR والAdmin والمدربين فعله؛ ورؤية البيانات تُتحكم بها بشكل منفصل عن صلاحيات الشاشات.

## استوديو وصول المستخدم (لوحة التحكم → User Access)

للمشرف العام فقط. واجهة مقسمة بدلاً من الشبكة القديمة:

| المنطقة | الغرض |
| --- | --- |
| **قائمة المستخدمين (يسار)** | بحث، فلترة بشرائح الأدوار (الكل / HR / Admin / مدرب)، صورة + شارة الدور — نفس تجربة محادثات المجموعة والرسائل المباشرة |
| **تبويب الحدود الأكاديمية** | إضافة صفوف UCA؛ قوائم البرنامج/المادة/الصف تعرض **عدد الصفوف والمدربين** (مثل QR Scanner) |
| **تبويب عدسة الرؤية** | لكل بُعد: **الكل** · **ضمن UCA** · **اختيار محدد** |
| **شرائح نشاط الصف** | عدد الصفوف، سير العمل، الحضور، الجلسات لكل صف UCA |
| **معاينة فعّالة (أسفل)** | ملخص مباشر لإعدادات المستخدم المحدد |

اضغط **مساعدة** أو زر الجولة لجولة Joyride بالعربية أو الإنجليزية.

### إضافة صف حدود أكاديمية

1. اختر مستخدماً من القائمة.
2. اختر **الفئة** (مطلوب).
3. اختيارياً: **البرنامج**، **المادة**، **الصف** — النص الفرعي يعرض الأعداد.
4. انقر **إضافة صف نطاق**.
5. راجع شرائح النشاط على كل صف.

### افتراضيات عدسة الرؤية

| البُعد | الافتراضي | استخدام HR النموذجي |
| --- | --- | --- |
| البرامج | ضمن UCA | البيانات التشغيلية في البرامج المعيّنة |
| المواد | ضمن UCA | نفس الشيء |
| الصفوف | ضمن UCA | نفس الشيء |
| **المدربون** | **الكل** | البحث عن أي مدرب للجدولة — حتى غير المعيّن |
| **القاعات** | **الكل** | البحث عن أي قاعة لتحليلات التوفر |

عند **الكل** للمدربين/القاعات: القوائم والتحليلات تعرض القائمة الكاملة؛ **الكتابة** تبقى ضمن UCA.

## الطبقات الخمس

| الطبقة | ما تتحكم به | من يضبطها |
| --- | --- | --- |
| **1. الهوية** | دور Keycloak | Keycloak / المستخدمون |
| **2. مصفوفة الصلاحيات** | الشاشات والإجراءات لكل دور | Super Admin فقط |
| **3. وصول المستخدم للفئة (UCA)** | البرامج والمواد والفصول المرئية | Super Admin فقط |
| **4. عدسة الرؤية** | مدى القوائم والتحليلات والتوفر (الكل / UCA / اختيار محدد) | Super Admin — **استوديو وصول المستخدم** |
| **5. ACL للموارد** | مشاركة Smart Drive، مشاركون في سير العمل | لكل ملف / workflow |

## Super Admin مقابل HR / Admin

| القدرة | Super Admin | HR / Admin |
| --- | --- | --- |
| نطاق البيانات | غير مقيد | **صفوف UCA فقط** — بدون UCA = لا بيانات أكاديمية |
| مصفوفة الصلاحيات | يحرر | لا يحرر |
| User Access | يدير | لا يدير |

HR و Admin **متساويان في نطاق البيانات**. الفرق بينهما فقط ما يضبطه Super Admin في المصفوفة.

## UCA

من **لوحة التحكم → User Access** (Super Admin):

- **canView** — قراءة البيانات في النطاق
- **canManage** — قراءة وكتابة ضمن النطاق

المدرب يرى أيضاً الفصول التي يدرّسها (اتحاد مع UCA).

## الرسوم البيانية والتحليلات

الرسوم (`BarChart`, `LineChart`, `PieChart`, …) تظهر في لوحة الملخص، التحليلات المتقدمة، ولوحة الطالب. **الرؤية تتبع عدسة الرؤية لكل بُعد**؛ البيانات التشغيلية (حضور، درجات) تبقى ضمن UCA.

## التوفر والتقويم (HR على البرنامج A)

صفوف UCA تحدد **مدى** الرؤية. المصفوفة تمنح **الوصول للشاشة** فقط — ولا توسّع البيانات.

| صف UCA | ما يراه HR/Admin |
| --- | --- |
| **البرنامج A** | كل **الصفوف** في البرنامج؛ **المدربون** المعيّنون لتلك الصفوف أو لديهم جلسات flex في البرنامج؛ **القاعات** المستخدمة؛ كل widgets لوحة الملخص (مدربون، صفوف، قاعات، حضور) بنفس النطاق |
| **مادة في البرنامج A** | صفوف تلك المادة فقط |
| **صف واحد** | ذلك الصف ومدرّبه وقاعته فقط |

**توفر المدرب (عرض حسب المدرب):** يعتمد على **عدسة الرؤية → المدربون**:
- **الكل** (افتراضي): كل المدربين في البحث والفلاتر.
- **ضمن UCA**: المدربون المرتبطون بالصفوف أو جلسات البرنامج فقط.
- **اختيار محدد**: المدربون المختارون يدوياً.

**توفر الصفوف:** صفوف داخل UCA فقط.

**توفر القاعات:** يعتمد على **عدسة الرؤية → القاعات**:
- **الكل** (افتراضي): كل القاعات للبحث والتحليلات.
- **ضمن UCA**: قاعات الصفوف/الجلسات في النطاق فقط.

**رسوم لوحة الملخص** (Overview، Sessions، Instructors، Classes، Rooms، Attendance…): نفس نطاق الـ API. الفلاتر تضيّق **داخل** UCA ولا تكشف بيانات خارج النطاق. المشرف العام يرى الكل.

## Visibility lens (استوديو وصول المستخدم)

لكل مستخدم، يحدد المشرف العام **مدى** كل بُعد في القوائم والتحليلات والتوفر — منفصل عن الحدود الأكاديمية:

| البُعد | الافتراضي | الخيارات |
| --- | --- | --- |
| البرامج | ضمن UCA | الكل · ضمن UCA · اختيار محدد |
| المواد | ضمن UCA | الكل · ضمن UCA · اختيار محدد |
| الصفوف | ضمن UCA | الكل · ضمن UCA · اختيار محدد |
| **المدربون** | **الكل** | الكل · ضمن UCA · اختيار محدد |
| **القاعات** | **الكل** | الكل · ضمن UCA · اختيار محدد |

**مثال — HR على البرنامج A:** UCA = البرنامج A للعمليات؛ المدربون/القاعات = الكل للبحث والجدولة.

**الكتابة** (الدرجات، الحضور، سير العمل) تبقى داخل UCA دائماً.
